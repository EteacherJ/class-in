# Class in

교사용 학급 대시보드 데스크톱 앱 (Windows · Mac)

시간표 · 출결 · 급식 · 과제 검사 · 타이머 · 발표자 뽑기 · 자리 바꾸기 등을 한 화면에서 쓰고,
전자칠판용 보조화면(아침 화면 · 판서 · 쉬는 시간 · 청소·종례 등)을 함께 띄울 수 있어요.

## 설치

[Releases](../../releases)에서 운영체제에 맞는 파일을 내려받아 설치해요.

- Windows: `Class-in-Setup-<버전>-win-x64.exe`
- Mac (Apple Silicon): `Class-in-<버전>-mac-arm64.zip`

## 개발

```bash
npm install
npm run dev        # 브라우저 미리보기
```

Electron + React + TypeScript + Vite
